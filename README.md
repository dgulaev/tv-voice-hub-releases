# TV Voice Hub

Голосовой поиск фильмов и сериалов на **Google TV**.  
Кнопка микрофона на пульте открывает Voice Hub: поиск по установленным приложениям (Lampa, NUM, Lift, Lazy, Prisma, Кинопоиск и др.) и карточка с трейлером, рейтингами, актёрами, отзывами и «где смотреть».

Здесь **публичные APK** и `version.json` для обновлений из приложения.

---

## Скачать

1. Откройте [Releases](https://github.com/dgulaev/tv-voice-hub-releases/releases).
2. Скачайте файл `.apk` нужной версии (например `TV-Voice-Hub-0.1.6.apk`).
3. Актуальная версия также указана в [`version.json`](./version.json).

В Releases лежит **release**-сборка (не debug): без `debuggable`, с minify и release-подписью.

Установка на приставку:

- через файловый менеджер / браузер на ТВ, **или**
- с компьютера: `adb install -r TV-Voice-Hub-….apk`

Разрешите установку из неизвестных источников, если система спросит.

## Первая настройка (обязательно)

Голос Google **остаётся**. Voice Hub добавляет док (чипы) на карточке фильма и свой голосовой поиск. Google-приложения не удаляются и не отключаются. Откат всегда рядом.

### 1. Режим разработчика

**Параметры → О устройстве** (или Система → О телевизоре) → найдите «Сборка» / «Версия Android TV» → нажмите **OK 7 раз**, пока не появится сообщение, что вы разработчик.

### 2. Отладка

**Параметры → Для разработчиков**:

- включите **Отладка по USB**;
- если есть **Беспроводная отладка** — тоже включите (удобно без кабеля);
- при запросе «Разрешить отладку» → **Разрешить**.

### 3. Запустить настройку в приложении

Откройте **TV Voice Hub** → раздел настройки приставки → **Инструкция** (по желанию) → **Запустить настройку**.

Индикатор дока должен стать зелёным. На TCL / Xiaomi / Google TV это безопасно: микрофон Google (Katniss) не отключается.

Если док не заработал: **Открыть спец. возможности** → включите **TV Voice Hub** вручную.

### 4. Запасной путь с компьютера

Если с ТВ не вышло: в приложении **Скопировать команды для компьютера** → на Mac:

```bash
adb connect IP:порт
# вставить скопированные команды в Terminal
```

## Как пользоваться

1. Нажмите **микрофон** на пульте (или откройте приложение с домашнего экрана).
2. Скажите название фильма / сериала (можно с годом).
3. Откройте карточку: трейлер, рейтинги TMDB/КП, актёры, отзывы, похожие.
4. Чипы **«Смотреть в …»** открывают поиск или карточку в установленном приложении (Lampa, NUM, Lift и т.д.).
5. История и закладки — на главном экране Hub; при связке с CUB / Luno / Lift возможна синхронизация закладок.

Дополнительно приложение умеет простые запросы вроде погоды, времени, калькулятора и открытия приложений — в зависимости от формулировки.

## Обновления

В настройках приложения: **Проверить обновление**.

Приложение читает публичный файл:

`https://raw.githubusercontent.com/dgulaev/tv-voice-hub-releases/main/version.json`

Если `versionCode` на GitHub больше, чем у вас — появится сообщение о новой версии.  
Скачайте APK по ссылке `apkUrl` из этого файла (или со страницы [Releases](https://github.com/dgulaev/tv-voice-hub-releases/releases)) и установите поверх (`adb install -r …` или через файловый менеджер).

Сейчас проверка сообщает о наличии обновления; установка APK — вручную.

---

## Откат (вернуть как было)

В настройках приставки нажмите **Вернуть настройки Google**.

- Док Voice Hub выключится.
- Голос Google останется.
- После отката спец. возможности после перезагрузки сами не вернутся — пока снова не нажмёте **Запустить настройку**.

---

## Важно

- Ничего не «ломаем»: не удаляем Google, не глушим пульт и не меняем громкость принудительно.
- Нужны **режим разработчика** и **отладка** хотя бы один раз для выдачи прав дока.
- Метаданные фильмов идут через облачный прокси приложения; без сети карточка может быть беднее.
- Репозиторий публичный: APK может скачать кто угодно по ссылке релиза.
