# TV Voice Hub

Хаб фильмов и сериалов для **Google TV** и **Android TV**.

- **Док** на карточке фильма в Google: чипы установленных приложений поверх системной карточки.
- **Голосовой поиск** и свой экран Hub: история, закладки, фильтры, поиск по библиотеке.
- Метаданные: трейлер, рейтинги (TMDB / Кинопоиск), актёры, отзывы, похожие, «где смотреть».

Голос Google **остаётся**. Voice Hub не удаляет и не отключает Google-приложения.

Здесь **публичные APK** и [`version.json`](./version.json) для проверки обновлений из приложения.

---

## Скачать

1. Откройте [Releases](https://github.com/dgulaev/tv-voice-hub-releases/releases).
2. Скачайте `.apk` нужной версии (например `TV-Voice-Hub-0.1.22.apk`).
3. Актуальная версия указана в [`version.json`](./version.json).

В Releases — **release**-сборка: без `debuggable`, с minify и release-подписью.

Установка:

- файловый менеджер / браузер на ТВ, **или**
- с компьютера: `adb install -r TV-Voice-Hub-….apk`

Разрешите установку из неизвестных источников, если система спросит.

## Первая настройка (обязательно)

### 1. Режим разработчика

**Параметры → О устройстве** → «Сборка» / «Версия Android TV» → **OK 7 раз**, пока не появится сообщение, что вы разработчик.

### 2. Отладка

**Параметры → Для разработчиков**:

- **Отладка по USB**;
- при наличии — **Беспроводная отладка**;
- «Разрешить отладку» → **Разрешить**.

### 3. Настройка в приложении

**TV Voice Hub** → настройка приставки → **Запустить настройку**.

Индикатор дока должен стать зелёным. На TCL / Xiaomi / Google TV это безопасно: микрофон Google не отключается.

Если док не заработал: **Открыть спец. возможности** → включите **TV Voice Hub** вручную.

### 4. Запасной путь с компьютера

В приложении **Скопировать команды для компьютера** → на Mac/PC:

```bash
adb connect IP:порт
# вставить скопированные команды в Terminal
```

## Как пользоваться

### Док на карточке Google

1. Откройте карточку фильма в Google (поиск / подсказки).
2. На **Google TV**: стрелка **вверх** по верхним кнопкам — вход в док; ещё раз вверх — выход.
3. На **Android TV** (без Entity): док на knowledge-карточке поиска или на экране с рядом приложений под YouTube.
4. Чипы открывают поиск или карточку в установленном приложении.

### Hub (главный экран)

- История и закладки, вкладки по источникам, поиск, сортировка, фильтр по жанрам.
- Импорт «Буду смотреть» из **Кинопоиска** (вход по QR) и синк закладок с подключёнными аккаунтами (CUB / Luno / Lift и др.).
- В карточке фильма: трейлер, рейтинги, актёры, похожие, открытие в провайдерах.
- TorrServe: скачать / поделиться / удалить раздачу.
- После просмотра в Jellyfin можно вернуться в хаб.
- «О приложении» → контакты.

Дополнительно: простые голосовые запросы (погода, время, калькулятор, открыть приложение) — в зависимости от формулировки.

## Обновления

В настройках: **Проверить обновление**.

Приложение читает:

`https://raw.githubusercontent.com/dgulaev/tv-voice-hub-releases/main/version.json`

Если `versionCode` на GitHub больше — появится сообщение о новой версии.  
Скачайте APK по `apkUrl` или со страницы [Releases](https://github.com/dgulaev/tv-voice-hub-releases/releases) и установите поверх.

Сейчас проверка сообщает о наличии обновления; установка APK — вручную.

---

## Откат

В настройках приставки: **Вернуть настройки Google**.

- Док Voice Hub выключится.
- Голос Google останется.
- После отката спец. возможности сами не вернутся до следующего **Запустить настройку**.

---

## Важно

- Не удаляем Google, не глушим пульт и не меняем громкость принудительно.
- Нужны **режим разработчика** и **отладка** хотя бы один раз для выдачи прав дока.
- Метаданные идут через облачный прокси; без сети карточка может быть беднее.
- Репозиторий публичный: APK доступен по ссылке релиза.
