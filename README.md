# TV Voice Hub

Хаб фильмов и сериалов для **Google TV** и **Android TV**.

Голос Google **остаётся**. Voice Hub добавляет док на карточке фильма, свой экран с историей и закладками, голосовой и текстовый поиск. Google-приложения не удаляются и не отключаются.

В этом репозитории — **публичные APK** и [`version.json`](./version.json) для обновлений из приложения.

[English README](./README.en.md)

## Скачать

1. [Releases](https://github.com/dgulaev/tv-voice-hub-releases/releases) → скачайте `.apk` (например `TV-Voice-Hub-0.1.22.apk`).
2. Актуальная версия также в [`version.json`](./version.json).

Сборка **release**: без `debuggable`, с minify и release-подписью.

Установка: файловый менеджер / браузер на ТВ или с ПК:

```bash
adb install -r TV-Voice-Hub-….apk
```

Разрешите установку из неизвестных источников, если система спросит.

## Первая настройка

### 1. Режим разработчика

**Параметры → О устройстве** → «Сборка» / «Версия Android TV» → **OK 7 раз**.

### 2. Отладка

**Параметры → Для разработчиков**: **Отладка по USB** (и **Беспроводная отладка**, если есть) → **Разрешить**.

### 3. В приложении

**TV Voice Hub** → настройка приставки → **Запустить настройку**.

Индикатор дока — зелёный. На TCL / Xiaomi / Google TV микрофон Google не отключается.

Если док не поднялся: **Открыть спец. возможности** → включите **TV Voice Hub**.

Запасной путь: **Скопировать команды для компьютера** → `adb connect IP:порт` → вставить команды в Terminal.

Откат: **Вернуть настройки Google** — док выключится, голос Google останется.

## Как пользоваться

### Док на карточке Google

1. Откройте карточку фильма в Google (поиск / подсказки).
2. **Google TV:** стрелка **вверх** по верхним кнопкам — вход в док; ещё раз вверх — выход.
3. **Android TV** (Shield и боксы без Entity): док на knowledge-карточке поиска или на экране с рядом приложений под YouTube. Опционально — скрыть док кнопкой **Назад** до нового поиска.
4. Чипы открывают поиск / карточку в установленном приложении; есть чип **«Торр»** для раздач прямо из дока.

Мышь в доке и хабе — переключатель в настройках дока.

### Hub (главный экран)

История, закладки, вкладки по источникам, поиск, сортировка, фильтр по жанрам, «Продолжить» по прогрессу сериалов.  
Карточка фильма: трейлер, рейтинги TMDB / Кинопоиск / IMDb, актёры, отзывы, похожие, «Смотреть в …».

Голос с пульта или открытие приложения с домашнего экрана — поиск по названию (можно с годом), по актёру, плюс простые запросы (погода, время, калькулятор, открыть приложение).

## Возможности

### Док и приставки

- Чипы провайдеров на карточке Google; настройка прозрачности, ширины и размера
- Google TV и отдельная ветка для Android TV (Shield, Amlogic и др.) без поломки Entity
- Подсказки по профилю приставки в настройке; «тихий Home» на части Amlogic / Ugoos
- Ряд / канал на главном экране ТВ (история или закладки)
- Режим «Включить логи» для отчётов с приставки (дамп окон, след дока)
- Инструкция и справка по настройке прямо в приложении

### Библиотека и карточка

- Поиск по истории и закладкам + глобальная карточка; клавиатура с пульта (RU/EN, 123, голос)
- Сортировка библиотеки, фильтр закладок по жанрам
- Поиск по актёру: сетка фильмографии, надёжный возврат фокуса
- Режим одного ряда: фон, описание, рейтинги
- Удаление из истории кнопкой в карточке (без случайного long-OK на сетке)
- Язык интерфейса: русский / English
- Анимации фокуса и скролла (можно отключить в «Внешний вид»)

### Синхронизация закладок

- CUB / Luno / Lift / NUM
- **Trakt** — вход по коду / QR, импорт и экспорт
- **Кинопоиск** — вход по QR, импорт «Буду смотреть», вкладка в меню, рейтинг КП на карточках
- Экспорт / импорт бэкапа хаба на диск приставки

### Торренты и просмотр

- Чип «Торр» в доке; модалка: сезоны, прогресс поиска, имя парсера
- Парсер JacRed: автозеркала, свой URL, сортировка, без дубликатов
- **TorrServe**: поиск в LAN / свой адрес; скачать, поделиться, удалить раздачу
- **TorrStream**, **Jellyfin** и другие провайдеры в доке и хабе; после Jellyfin — возврат в хаб
- Список «Смотреть в» настраивается: вкл/выкл и порядок

### Обновления и поддержка

- **Проверить обновление** → **Скачать и установить** (прогресс + системный установщик)
- Красная точка на «Настройки», если есть новая версия
- «О приложении» → контакты
- Метаданные и постеры через облачный прокси приложения (+ запасные зеркала)

## Обновления

В настройках: **Проверить обновление**.

Приложение читает:

`https://raw.githubusercontent.com/dgulaev/tv-voice-hub-releases/main/version.json`

Если `versionCode` больше — скачайте APK по `apkUrl` или со страницы [Releases](https://github.com/dgulaev/tv-voice-hub-releases/releases) и установите поверх (или кнопкой **Скачать и установить** в приложении).

---

## Важно

- Не удаляем Google, не глушим пульт и не меняем громкость принудительно.
- Нужны режим разработчика и отладка хотя бы один раз для прав дока.
- Без сети карточка с метаданными может быть беднее.
- Репозиторий публичный: APK доступен по ссылке релиза.
